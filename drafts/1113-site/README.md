## Image URL scheme
Images are not in the repo; they are served from the NAS Web Station:

```
https://songfamhome.synology.me/portfolio2026/<project>[/<sub-work>]/<NN>-<short-name>.webp        long edge <= 2560 px
https://songfamhome.synology.me/portfolio2026/<project>[/<sub-work>]/<NN>-<short-name>@1280.webp   long edge <= 1280 px
```

- NAS path: `/volume1/web/portfolio2026/...` (WebP q82, aspect kept, never upscaled). `NN` = order on the page within that folder.
- `<project>` in mercedes, kia2022, hyundai2022, kia2021, vishow, niva. Sub-work folders e.g. `kia2022/mocamper/`.
- Manifest: `https://songfamhome.synology.me/portfolio2026/manifest.json` — project, sections, images with src, w, h, alt, caption, nas_source_path, crop, evidence.
- Pages use `<img src=@1280 srcset="@1280 1280w, full <w>w" width height loading=lazy>`.
